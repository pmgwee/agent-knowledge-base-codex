Cross-agent persistent memory · Rust · Windows · local-only

The secondary brain, end to end

Every Claude Code and Codex session on this machine is captured to an append-only SQLite ledger on C:, distilled by an LLM into cited memories, searched by three fused channels, and projected to Markdown you can open in Obsidian. Nothing leaves the machine except the consolidation call.

Lifecycle coverage — honest reading

StageStatusWhat is actually true
Collect Complete Both agents, automatically, with no per-session action. Transcript-based rather than hook-based, so nothing is lost when a hook fails to fire.
Organize Complete Events become typed memories with event:<uuid> citations, wikilinks derived from shared evidence, and index pages — a real structure, not a pile of embeddings.
Evolve Complete Supersession, surfaced conflicts, manual withdrawal, access counting, derived staleness, and brain lint to find what has drifted. Automatic eviction is deliberately gated on thirty days of access data rather than missing.
Use Complete Push at session start for Claude Code and Codex; pull on demand via CLI and six MCP tools. Hybrid retrieval reaches the pull path; the orientation itself is still recency-shaped.
Govern Complete Inspect, trust, export and withdraw all exist — dashboard, verify memory, verified backups, restore drills, export, and forget as a tombstone. Scoping to a subset of a project is the one thing still absent.

Subject pages — what decides a subject Live

The gap the LLM Wiki pattern names is that nothing compounds per subject. The hard part was never rendering the page; it was deciding what a subject is without a model asserting one, since an invented subject is an unsourced claim in a vault whose whole property is that nothing is unsourced. Not being built, on purpose

Vault write-time validation

Guards an agent hand-writing Markdown. Nothing here does — notes are generated and checksum-verified, so malformed frontmatter is unconstructable rather than caught.

Orphan cross-linker

Broken backlinks are impossible by construction and test-pinned. An orphan here is honest: a memory that genuinely shares no evidence with any other.

Team memory

Namespaced shared and private scopes across members. Real cost, zero value on a single-operator system.

Engine console pages

Workers, functions, triggers, KV browser. Those expose a generic function runtime; reproducing them would mean inventing the runtime first.
