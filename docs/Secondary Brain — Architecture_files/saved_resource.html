The secondary brain, end to end

Every Claude Code and Codex session on this machine is captured to an append-only SQLite ledger on C:, distilled by an LLM into cited memories, searched by three fused channels, and projected to Markdown you can open in Obsidian. Nothing leaves the machine except the consolidation call.

Lifecycle coverage — honest reading

StageStatusWhat is actually true
Collect Complete Both agents, automatically, with no per-session action. Transcript-based rather than hook-based, so nothing is lost when a hook fails to fire.
Organize Complete Events become typed memories with event:<uuid> citations, wikilinks derived from shared evidence, and index pages — a real structure, not a pile of embeddings.
Evolve Partial Supersession works and conflicts are surfaced. There is no decay, no importance scoring, no forgetting, and no re-reasoning over old memories as new ones arrive.
Use Complete Push at session start for Claude Code and Codex; pull on demand via CLI and six MCP tools. Hybrid retrieval reaches the pull path; the orientation itself is still recency-shaped.
Govern Thin Inspect and trust are strong — dashboard, provenance, verified backups, restore drills. Correct, delete, export and scope are missing entirely.
