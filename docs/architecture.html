The secondary brain, end to end

Every Claude Code and Codex session on this machine is captured to an append-only SQLite ledger on C:, distilled by an LLM into cited memories, searched by four fused channels, and projected to Markdown you can open in Obsidian. Nothing leaves the machine except the consolidation call.

R@10 is identical, and that is the whole finding

The answering session is still retrieved — re-ranking moves it down, out of the top five, and spends 25% more wall-clock to do it. MRR falls further than R@5 does, so the cost is spread through the ordering rather than concentrated in one lost instance. Isolated beforehand on a fixture: holding the distractor constant and changing one word of the answer, ship → deploy, moved its score 10.2 points — the model's entire range — for a sentence meaning the same thing. The bi-encoder fails the same cases in the same direction, which makes this structural rather than a weak checkpoint. The fix for a vocabulary gap is query expansion, not a second scoring model.

Lifecycle coverage — honest reading

StageStatusWhat is actually true
Collect Complete Both agents, automatically, with no per-session action. Transcript-based rather than hook-based, so nothing is lost when a hook fails to fire — and the session boundary is now observed too, which no amount of transcript reading could have supplied.
Organize Complete Events become typed memories with event:<uuid> citations, wikilinks derived from shared evidence, index and subject pages — a real structure, not a pile of embeddings.
Evolve Complete Supersession, surfaced conflicts, manual withdrawal, access counting, derived staleness, brain lint, and eviction that refuses to run until thirty days of access data exist. Gated by arithmetic, not missing.
Use Complete Push at session start for both harnesses; pull on demand via CLI and six MCP tools. Hybrid retrieval reaches the pull path; the orientation is recency-shaped by design and is ranked by relevance within that.
Govern Complete Inspect, trust, export and withdraw all exist — dashboard, verify memory, verified backups, restore drills, export, forget as a tombstone, evict with its gate. Scoping export to a subset of a project is the one thing still absent.

Open, and needing a human

Four contradictions and 660 islands

brain lint reports memories that disagree with each other, four dated to the Unix epoch (undated rather than old), and 660 of 2,097 sharing evidence with nothing else so no wikilink reaches them. Building the instrument was the deliverable; deciding which side of a contradiction is true is not something derivation can do.

One number that could not be traced

A 93.2% R@5 figure appears in an earlier roadmap and in no document or commit. The recorded numbers are per-category: 63.3% → 90.0% on single-session-preference. Those are not the same measurement and should not be quoted as one.
