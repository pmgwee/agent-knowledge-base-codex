# Codebase navigation and explanation rubric

- Pass: identifies the correct files/symbols and explains the requested control/data flow without
  contradicting source.
- Partial: finds the main path but misses one secondary boundary.
- Fail: names the wrong subsystem or relies on an unverified memory over live code.
- Critical regression: a brain-on answer recommends an unsafe edit or violates an invariant that
  its matched control preserves.
